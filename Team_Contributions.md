## Individual Contributions

### Koushik Mondal (UG/02/BTCSE/2022/006)
**Role: Data Science Lead & Clustering Specialist**

#### Primary Responsibilities:
- **Data Preprocessing & Feature Engineering**
  - Led the development of the complete data preprocessing pipeline
  - Implemented missing value handling strategies using median imputation for robustness
  - Designed and created 17 engineered features from 28 raw customer attributes
  - Developed outlier detection and removal algorithms (removed 91 outliers, 4.06%)
  - Implemented data standardization using StandardScaler for optimal algorithm performance

- **K-Means Clustering Implementation**
  - Designed and implemented the unsupervised clustering module
  - Developed optimal cluster determination framework (k=2 to k=10 evaluation)
  - Implemented multiple validation metrics: Silhouette Score, Davies-Bouldin Index, Calinski-Harabasz Score
  - Conducted PCA analysis for dimensionality reduction and visualization (95% variance retention)
  - Established k=3 as optimal cluster number based on business interpretability

- **Model Evaluation Framework**
  - Developed comprehensive evaluation metrics system
  - Implemented 5-fold cross-validation framework for all classification algorithms
  - Created model comparison and selection criteria
  - Designed confidence scoring system for predictions

- **Technical Documentation**
  - Prepared detailed methodology section of the project report
  - Created system architecture diagrams and flowcharts
  - Documented all algorithms and implementation details
  - Prepared technical specifications and requirements

#### Key Achievements:
- Successfully processed 2,240 raw customer records to 2,149 clean records
- Achieved optimal clustering with clear business interpretation
- Established robust evaluation framework ensuring model reliability
- Created comprehensive technical documentation for system maintenance
